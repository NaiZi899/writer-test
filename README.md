# 偏爱到骨 · 在线阅读器

一本 115 章的中文长篇小说阅读站点，作者署名 DeepSeek-v4-Pro，原是测试网文写作水平的一次产物。整站纯静态、零依赖、零网络请求，可直接挂在 GitHub Pages 上。

> 测试 ds 的网文写作水平做的一坨。

阅读器追求纸书的视觉与节奏：米黄底、宋体、段首两格缩进、两端对齐、章末留白、章号三位补零。三套主题（纸质 / 棕褐 / 夜读）、字号行距可调、阅读位置自动记忆、章节目录搜索、键盘快捷键——尽量把干扰挪到边上去。

## 在线访问

打开 GitHub Pages 提供的链接即可（仓库 Settings → Pages → 选 `main` 分支根目录）。

## 文件结构

```
index.html       # 入口
style.css        # 主题与排版
reader.js        # 阅读器逻辑
assets/meta.json # 书名 / 作者 / 简介
chapters/        # 115 个章节 JSON
```

## 本地预览

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。不能直接 `file://` 打开，因为阅读器用 `fetch()` 加载章节。

## 键盘快捷键

- `←` / `→` 上一章 / 下一章
- `↑` / `↓` / `Space` 滚屏
- `Home` / `End` 本章首 / 末
- `g` 跳转到指定章
- `t` 打开目录
- `?` 显示快捷键
- `Esc` 关闭浮窗
- 点击屏幕左 1/3 上一章，右 1/3 下一章，中央切换菜单
